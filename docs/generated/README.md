Files in this directory (`COMMAND_REFERENCE.md`, `EVENT_REFERENCE.md`,
`BUILD_IDENTITY.md`, and the rest) are a presentation layer emitted by an
earlier compile. Live command/event/machine/projection counts and the current
build hash come from `generated/registries/` and
`generated/compiler-certification.json`, as recorded in
`docs/ARCHITECTURE.md`.
